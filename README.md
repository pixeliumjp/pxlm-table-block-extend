# Pxlm Table Block Extend

WordPress 標準のテーブルブロックで、見出しセルの設定、セルの結合・解除、ヘッダー行やフッター行の追加ができます。セルに画像やリストを入れたいときは、その表を「ブロック対応テーブル」に変換できます。

[WordPress Playground でサンプルの時間割を編集する](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/pixeliumjp/pxlm-table-block-extend/main/blueprint.json)

## サンプルで試す

1. 表の中をクリックし、ツールバーから「セルを編集」を開きます。「会場」「午前」「午後」を順にクリックして「列見出し (th)」を押すと、3 つのセルが `<th scope="col">` に変わります。行見出しには `<th scope="row">` を使えます。
2. 「選択をクリア」を押し、「講演」をクリックしてから Shift キーを押しながら「交流会」をクリックします。「結合」を押すと、2 つの内容が改行でつながります。同じセクション内なら縦方向や複数行・複数列の長方形も結合できます。
3. 結合したまま「ヘッダー行を追加」または「フッター行を追加」を押してみてください。繰り返し押すと複数行追加できます。標準テーブルでは、ブロック設定にあるヘッダー・フッターのスイッチからも各セクションを追加できます。
4. ダイアログを閉じ、表のツールバーで「セルにブロックを使う」を選ぶと、「ブロック対応テーブル」(`pxlm/table`) に変わります。既存の文字やリンクはセル内の段落に引き継がれます。セルを選び、「＋」から画像やリストなどを追加してください。

## 変換後の編集

セルを結合すると、中にあるブロックが左上から行順に 1 つのセルへ移ります。「結合を解除」を押すと、ブロックは左上に残り、ほかのセルは空になります。変換後の表をブロックエディターで再編集するには、このプラグインを有効にしておいてください。

結合のない表では本文の行や列も追加・削除できます。「ブロック対応テーブル」では「セルを編集」を開き、基準にするセルを 1 つ選んで操作します。

## インストール

WordPress 7.0 以降、PHP 7.4 以降で利用できます。次の ZIP を管理画面の「プラグインを追加」→「プラグインのアップロード」からインストールして有効化します。[プラグインの ZIP をダウンロード](https://raw.githubusercontent.com/pixeliumjp/pxlm-table-block-extend/main/dist/pxlm-table-block-extend.zip)
