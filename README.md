# Pxlm Table Block Extend

WordPress 標準のテーブルブロックで、見出しセルの設定、セルの結合・解除、ヘッダー行やフッター行の追加ができます。セルに画像やリストを入れたいときは、その表を「ブロック対応テーブル」に変換できます。

[WordPress Playground でサンプルの時間割を編集する](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/pixeliumjp/pxlm-table-block-extend/main/blueprint.json)

## 標準テーブルでセルを選ぶ

セルをクリックすると、その 1 セルが選ばれます。Mac では ⌘、Windows では Ctrl を押しながらクリックすると、離れたセルも 1 つずつ選択・解除できます。始点をクリックしてから終点を Shift＋クリックすると、同じセクション内の長方形を選べます。

選んだセルには、表のツールバーの「セル操作」から変更を適用します。たとえば時間割の「会場」から「午後」までを選び、「列見出し (th)」を押すと、3 つのセルが `<th scope="col">` に変わります。「行見出し (th)」なら `<th scope="row">` になります。

### 2 行 × 3 列を結合してみる

サンプルの「ホール」をクリックし、右下の「ワークショップ」を Shift＋クリックします。この 6 セルに対する「セル操作」の結果は次のとおりです。

| 操作 | 結合後の形 |
| --- | --- |
| 横方向に結合 | 1 行目の 3 セル、2 行目の 3 セルがそれぞれまとまり、上下に 2 セル残ります。 |
| 縦方向に結合 | 各列の上下 2 セルがまとまり、横に 3 セル並びます。 |
| すべて結合 | 選んだ 6 セルが 1 つになります。 |

標準テーブルでは、結合したセルの内容を改行でつなぎます。「結合を解除」を押すと、内容は元の結合範囲の左上に残ります。別の結合方法を同じサンプルで試すには、エディターの「元に戻す」を使ってください。

「セルを編集」からも選択と結合ができます。このダイアログでは、修飾キーを押さずにクリックやタップでセルを 1 つずつ選択・解除できます。

## ヘッダー行とフッター行

標準テーブルでは「セルを編集」、ブロック対応テーブルでは表の下の操作欄から「ヘッダー行を追加」「フッター行を追加」を選びます。結合セルがあっても追加でき、繰り返し押せば複数行にできます。標準テーブルでは、ブロック設定にあるヘッダー・フッターのスイッチからも各セクションを追加できます。

## セルに画像やリストを入れる

標準テーブルのツールバーで「セルにブロックを使う」を選ぶと、表が「ブロック対応テーブル」(`pxlm/table`) に変わります。セルの文字やリンクは段落に引き継がれます。セルを選び、「＋」から画像やリストなどを追加してください。

変換後は、表の下の「セル選択」をオンにすると、クリックやタップだけでセルを 1 つずつ選択・解除できます。Shift＋クリックの範囲選択も使えます。「セル操作」から見出しの変更や結合を行い、「セル選択」をオフにすると、再びセル内のブロックを編集できます。

結合すると、各セルのブロックが左上から行順に新しいセルへ移ります。「結合を解除」すると、ブロックは結合範囲の左上に残ります。変換後の表を再編集するには、このプラグインを有効にしておいてください。

結合のない表では本文の行や列も追加・削除できます。ブロック対応テーブルでは「セルを編集」を開き、基準にするセルを 1 つ選んで「行・列の操作」を開いてください。

## インストール

WordPress 7.0 以降、PHP 7.4 以降で利用できます。次の ZIP を管理画面の「プラグインを追加」→「プラグインのアップロード」からインストールして有効化します。[プラグインの ZIP をダウンロード](https://raw.githubusercontent.com/pixeliumjp/pxlm-table-block-extend/main/dist/pxlm-table-block-extend.zip)
